# Учебный проект по тестированию с pytest

Небольшая песочница для освоения автоматического тестирования на Python. В проекте есть простая бизнес-логика, готовые тесты и самостоятельные упражнения.

## Быстрый старт

Нужен Python 3.10 или новее.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
pytest
```

Если PowerShell не позволяет активировать окружение, тесты можно запускать так:

```powershell
.\.venv\Scripts\python.exe -m pytest
```

## Что изучать по порядку

1. Откройте `tests/test_calculator.py`: базовые проверки через `assert` и проверка исключений.
2. Изучите `tests/test_validators.py`: параметризация (`@pytest.mark.parametrize`).
3. Решите задания из `exercises/test_shopping_cart.py`. Тесты в нём специально помечены как `xfail`, поэтому общий запуск остаётся зелёным.
4. Уберите `xfail` у одного задания и реализуйте тест или функцию, затем снова запустите `pytest`.

## Полезные команды

```powershell
pytest -v                         # подробный отчёт
pytest tests/test_calculator.py   # один файл
pytest -k "divide"                # тесты по части имени
pytest -x                         # остановиться после первой ошибки
pytest --cov=study_project         # покрытие, если установлен pytest-cov
```

## Идеи для продолжения

- Добавьте фикстуру с корзиной покупок.
- Проверьте граничные значения: пустая строка, ноль, отрицательная цена.
- Напишите тест, который воспроизводит ошибку, затем исправьте код.
- Добавьте интеграционный тест для оформления заказа.
